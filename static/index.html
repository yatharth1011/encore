One-time setup

Connect Encore to Google

Encore talks to YouTube with your own Google Cloud OAuth client, so nothing passes through anyone else's server. This takes about five minutes, once.

  1. Open Google Cloud Console and create a project (any name).
  2. Enable the YouTube Data API v3 for it.
  3. Under Google Auth Platform, configure the consent screen: External, your email as support contact. Then on Audience click Publish app — in “Testing” mode Google signs you out every 7 days.
  4. Under Clients, create an OAuth client of type Desktop app and download its JSON.
